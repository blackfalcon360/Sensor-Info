# Sensor Info

فون کے تمام سینسرز اور GNSS (GPS, GLONASS, Galileo, BeiDou, QZSS, NavIC) کی معلومات۔

## ایپ کیا کرتی ہے
- سینسرز ٹیب: فون میں کل سینسرز، عام سینسرز کی ✔/✖ فہرست، ہر سینسر کا نام، بنانے والا، قسم؛ ٹیپ پر رینج، ریزولوشن، بجلی، ریٹ، اور لائیو ریڈنگ۔
- GNSS ٹیب: ہر نظام (GPS, GLONASS, Galileo, BeiDou, QZSS, NavIC/IRNSS, SBAS) کے لیے: ابھی ٹریک ہو رہا / پہلے ٹریک ہو چکا / نہیں دیکھا، سیٹلائٹس کی تعداد، فکس میں کتنے، بہترین سگنل (dB-Hz)، بینڈ (L1, L5 وغیرہ؛ اینڈرائیڈ 8+)، اور سیٹلائٹس کی فہرست (سگنل، بلندی، زاویہ)۔ اینڈرائیڈ 9+ پر GNSS چپ کا ماڈل اور سال۔
- فون ٹیب: ماڈل، ہارڈویئر/بورڈ، چپ سیٹ (اینڈرائیڈ 12+)، ہارڈویئر خصوصیات (NFC, UWB, Wi-Fi RTT وغیرہ)، اور پوری رپورٹ شیئر کرنے کا بٹن۔
- زبان: اردو / English / العربية؛ لائٹ اور ڈارک موڈ؛ باہر نکلنے سے پہلے تصدیق۔

## بِلڈ
1. فولڈر GitHub پر اپ لوڈ کریں۔
2. Actions میں "Build APK" چلے گا۔
3. Artifacts سے `SensorInfo-APK` ڈاؤن لوڈ کریں۔

## پابندیاں
- صرف portrait؛ AndroidX یا بیرونی لائبریری نہیں؛ انٹرنیٹ نہیں؛ صرف لوکیشن کی اجازت (GNSS کے لیے)۔
- اینڈرائیڈ یہ نہیں بتاتا کہ چپ کون سے نظام سپورٹ کرتی ہے؛ ایپ صرف وہ نظام دکھاتی ہے جن کے سیٹلائٹس واقعی ٹریک ہوئے۔ "نہیں دیکھا" کا مطلب "سپورٹ نہیں" نہیں؛ کھلے آسمان تلے چند منٹ انتظار کریں۔ پہلے ٹریک ہونے والے نظام فون میں یاد رہتے ہیں۔
- دل کی دھڑکن اور قدم جیسے سینسرز کی لائیو ریڈنگ کے لیے اینڈرائیڈ الگ اجازت مانگتا ہے جو ایپ نہیں مانگتی۔
